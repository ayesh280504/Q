# Q — Investor one-pager

## Problem

Resident and open-format DJs lose creative control when booth software fights venue Wi‑Fi, or when crowd tools feel like “beginner DJ” automation (Virtual DJ). Their #1 feedback: **stability above all else** — a frozen laptop mid-set is career damage.

## Solution

**Q** is local-first booth software plus an optional crowd layer:

- **Desktop (Windows):** Reads Serato/Rekordbox libraries and history on the laptop. Queue, accept/decline, transition hints — **never auto-mixes**.
- **Crowd (web):** Guests scan QR on their own LTE; requests sit in the cloud; the booth **pulls** them asynchronously.
- **Phone booth app (roadmap):** Glanceable accept/decline and live BPM/key without alt-tabbing Serato.

Music files never leave the DJ's machine. Worst case on bad Wi‑Fi: requests arrive late; **the set keeps playing**.

## Traction / validation plan

- v0.1.7 shipped: Rekordbox + Serato, library profiles, permanent `@handle` QR, Pro DJ Link path
- Phase 0: dual-software gig validation (NYC/Wisconsin DJ interviews)
- Phase 1: network hardening (timeouts, 15s poll default, offline accept)

## Business model (direction)

- Free: booth + crowd requests + community profile
- **Q Pro:** transition hints (Camelot, BPM bridges), cross-crate intelligence, advanced analytics

## Moat

- Deep Serato/Rekordbox integration (file formats, history, crates) — high switching cost for working DJs
- Trust positioning: suggestion-only, not automation
- Permanent QR + DJ identity graph (Phase 2 social)
