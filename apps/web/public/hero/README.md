# Hero scroll video

The landing hero scrubs this file as you scroll (like a frame-by-frame animation).

**Current file:** `cdj-scroll.mp4`

To replace it, drop a new MP4 here and keep the same name, or update `VIDEO_SRC` in `apps/web/src/components/HeroScrollVideo.tsx`.

Tips for best results:

- **H.264 MP4**, no audio needed (muted in the browser)
- **30fps or 60fps**, 2–8 seconds length works well with the hero scroll height
- Start frame = top of hero, end frame = bottom of hero
